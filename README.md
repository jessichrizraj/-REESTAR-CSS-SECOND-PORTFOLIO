# 🍽️ Reestar Portfolio Website

## 📖 Project Description

Reestar Portfolio is a simple and visually appealing website developed using HTML and basic CSS. This project is created to practice and improve my frontend web development skills by building a website with a clean design, attractive layout, and user-friendly interface.

The website focuses on presenting content in an organized way with proper spacing, alignment, colors, and typography. It demonstrates the basic concepts of HTML structure and CSS styling.

This project is part of my learning journey in web development, where I explore how to transform simple HTML elements into an attractive and functional website using CSS.

## ✨ Key Features

- Clean and attractive website design.
- Simple and user-friendly interface.
- Well-organized content sections.
- Attractive colors and typography.
- Proper spacing and alignment.
- Easy navigation between sections.
- Basic CSS styling and layout techniques.
- Beginner-friendly frontend project.

## 💻 Technologies Used

### HTML5
- Used to create the basic structure of the website.
- Organized the content using HTML elements.
- Created headings, paragraphs, links, and sections.

### CSS3
- Used to style the website.
- Applied colors, fonts, margins, and padding.
- Improved the overall appearance of the website.
- Used CSS properties to create an attractive layout.
